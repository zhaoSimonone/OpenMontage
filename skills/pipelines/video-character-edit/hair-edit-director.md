# Hair Edit Director - Video Character Edit

Use the accepted outfit output as the input. Change only the hairstyle or the
explicit hair description. Preserve face structure, clothing, body, pose,
motion timing, camera, background, lighting, and audio.

Inspect hairline transitions, occlusion around the face and shoulders, motion
blur, and frame-to-frame flicker. Keep every attempt under the project assets
directory and require approval before face locking.
