# Outfit Edit Director - Video Character Edit

Start from the accepted preprocessed source segment. The prompt may change only
the target person's clothing and must explicitly preserve face, hair, body,
pose, motion timing, camera, background, lighting, and audio.

Before a paid call, announce the exact provider, model, segment, references,
prompt contract, and estimate. Save every attempt and probe its output. A
successful API response is not acceptance; create a matched-timestamp review
and wait for human approval.

If the provider only generates a new video from references, stop with a
capability blocker rather than treating it as an edit.
