# Face Lock Director - Video Character Edit

The face-lock stage is a dedicated identity operation. It may use the approved
face reference only to replace the target face region. It must not redesign
hair, clothing, body, background, camera, or expressions.

FaceSwap/FaceFusion is not currently bundled with OpenMontage. If no registered
`face_identity_lock` tool is available, mark the stage blocked and explain the
missing provider. Do not substitute a generic video-generation prompt or an
unapproved face enhancer.

Review expression preservation, gaze, occlusion, hairline boundaries, and
temporal stability before acceptance.
