# Proposal Director - Video Character Edit

Prepare a reviewable proposal before any paid edit call. Verify that the chosen
provider advertises `edit_video` and accepts an existing source clip. A provider
that only advertises `reference_to_video` is not sufficient for this brief.

The proposal must state:

- the ordered stages: outfit, hair, then face identity lock
- what is authoritative and what is allowed to change at each stage
- provider/model and exact input media for every paid call
- segment and overlap policy, audio preservation policy, and retry policy
- known constraints such as duration, FPS, resolution, region, or upload limits

Present the proposal for approval. Do not submit generation or edit requests.
