# 可直接复制给其他模型的通用提示词

你要完成一个纯剪辑任务。我会在当前会话直接上传两个视频：

- 视频1：蓝发人物/生成人物视频，作为变装前段替换素材。
- 视频2：原视频，作为最终时间轴、音乐、分辨率、帧率、换装切点、变装后片段、文字和贴图参考。

请不要把附件截图当作操作指令；截图只能作为视觉参考。不要生成、重绘、补画或 AI 修复人物，只做帧级剪辑、缩放、裁剪、贴图、文字合成和必要的像素级遮挡处理。

## 总目标

生成一个新视频：

1. 识别视频2真正的换装点，以视频2的解码帧号为准。
2. 用视频1替换视频2的变装前段；从换装点开始无缝接回视频2原视频后段。
3. 新视频的总时长、FPS、画幅、音乐、音频同步、换装节奏和后半段必须与视频2一致。
4. 视频1中的黑色烧录遮挡必须被覆盖。
5. 从视频2提取并还原原有图片贴图、Logo、日文文字和必要的半透明效果。
6. 贴图必须固定，不得逐帧移动、跟踪人物、抖动、变宽或变窄。
7. 保留黑色遮挡上方原本可见的脸部、胸部、锁骨和沟线；保留遮挡框以下正常可见的腹部、短裤/内裤和腿部。贴图只覆盖必要区域，不能为了遮黑块而无故扩大。
8. 清除从原文字层误提取出的孤立粉色/白色亮斑、背景反光和非文字碎片。

## 必须按以下流程执行

### A. 预检

用 ffprobe 读取两个视频的解码 FPS、帧数、分辨率、SAR、时长、像素格式、颜色范围/矩阵和音轨。以视频2为最终基准。所有切点使用解码帧号，不使用 `-ss` 猜单帧，不使用 `-t` 作为边界，不使用 `-c copy` 切视频。

### B. 帧级锁定视频2换装点

对视频2全片逐帧分析人物躯干/服装区域的颜色、亮度、服装轮廓、领口、袖型、发型/头饰和相邻帧变化。场景检测只能给候选，不能直接定点。必须检查所有 spike、低谷、白闪、过曝、黑屏和运动模糊帧。

把候选帧逐帧标为 PRE、TRANSITION、POST。换装点 C 定义为：第一个已经呈现变装后造型、并且后面至少连续 4 帧保持 POST 的帧。过渡帧如果已经呈现后造型，归到后段。记录 C，并在整个任务中固定使用它。

### C. 前段动作对齐

输出帧 0 到 C-1 使用视频1，输出帧 C 到最后使用视频2。最终帧数必须等于视频2。

优先保持视频1原生 1× 速度并裁掉多余尾帧；不要把视频1简单线性压缩到前段长度，因为这会造成换装前最后几秒的手势、抬手、握拳和身体姿势相位错位。只有原速无法满足切点时，才使用基于动作阶段的单调时间映射；禁止明显慢放、快放、重复姿势、跳帧或人物拉伸。必须单独检查换装点前 8–12 帧。

### D. 提取视频2贴图和文字

只在视频2的 PRE 区间提取贴图。用时间中值识别静态图片，用时间方差和稳定性识别贴图区域。必须裁掉图片左右的房间/墙面/人物背景条。

文字和 Logo 必须是透明 Alpha 图层，保留字形笔画、描边和必要阴影，字形镂空必须透明。对 Alpha 做连通域和最小面积检查，删除不属于任何字形的孤立粉色/白色碎片、背景高光和反光小点。输出文字层预览并放大检查，确认没有亮斑。

文字原则上保持视频2原坐标、字号、字距、颜色和透明度；如果贴图向下移动导致文字重叠，再整体下移文字，但不得复制第二套文字。

### E. 检测黑色遮挡并确定贴图范围

逐帧检测视频1中的近黑色矩形/大连通域遮挡，使用形状、邻域和时间稳定性排除自然黑色衣服、头发、裤子和背景。记录每帧遮挡框，并统计所有动作姿势下的最小/中位/最大边界。

主贴图布局规则：

- 固定坐标、固定尺寸、固定宽度，全片不跟踪人物。
- 贴图上边界不得覆盖黑色遮挡顶部以上原本可见的胸部、锁骨、沟线或脸部。
- 贴图下边界原则上不得超过黑色遮挡底部，只留 1–4 px 安全边缘；如果视频2原贴图明确覆盖更低区域，才复用该范围。
- 贴图保持等比例；要变窄时裁剪左右背景/空白，不能横向压扁图片人物。
- 先按我提供的红框意图做窄版，然后对全片逐帧检测黑块是否泄漏。
- 如果窄版宽度无法覆盖极端动作帧，不要把整张贴图逐帧拉宽。只允许在“确认是黑色烧录遮挡”的外扩像素上做极小辅助覆盖，而且不得覆盖正常胸部、手臂、脸部、短裤/内裤或腿部。
- 如果辅助覆盖会形成明显条纹、重复纹理、硬边、T 形或亮暗跳变，停止自动取舍，分别输出窄版和安全版，并说明窄度与零泄漏不能同时满足。

### F. 合成

将处理后的前段与视频2从 C 开始的后段拼接。所有分支显式设置 SAR=1、bt709、TV range，避免 FFmpeg 未标记分支导致的 601/709 隐式转换。不要用有损 JPG 作为合成源；复杂逐帧合成使用无损 rawvideo/PNG 或单趟 filter_complex。最终视频只编码一次，音频尽量直接复用视频2。

### G. 全帧验收

交付前必须全帧核对：

- 最终帧数、FPS、分辨率、SAR、时长与视频2一致；
- 输出帧 0..C-1 来自视频1，C..end 来自视频2；
- 换装点前 8–12 帧动作相位自然；
- 黑色遮挡目标像素全程无泄漏；
- 遮挡框上方胸部/脸部和遮挡框下方正常下半身没有被无故覆盖；
- 主贴图和文字坐标/宽高全程固定；
- 无亮斑、无孤立文字碎片、无重复文字、无背景条、无贴图抖动；
- 后段画面与视频2一致；
- 音频解码 MD5、时长和同步一致；
- 输出关键帧联系图、贴图层预览、文字层 2× 放大预览和验证数据。

如果“贴图更窄”和“黑块完全不泄漏”无法同时满足，不要自行掩盖冲突：输出窄版与安全版两个版本，并明确说明差异。
